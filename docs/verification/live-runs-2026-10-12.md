# Real-model verification, 2026-10-12

**English** · Every exercise of every available lesson was run once in each runtime language against a real model, after the runtime became bilingual. This file records what was run and what was found; it is a dated record, not a guarantee for other models.

## Results

- Every run recorded the requested language.
- English runs: no CJK character in any event (platform or model text); the model answered in English every time.
- Observation points: 469 of 482 were present in the real events. The 13 absent ones depend on choices the model is free to make (for example, no reminder was needed because the model kept its checklist updated; the first regex passed every test so no revision happened). The lesson text treats these as conditional evidence.
- No run ended in an unexpected error. "Failed" verdicts were only the ones lessons build in on purpose (static-plan arm, injected faults).

## Text corrected after the runs

- reflection-revision, orchestrator-evaluator: guide steps that assumed a revision always happens are now conditional on the reviewer or tests asking for one.
- text-actions: "the model often writes an Observation itself without `stop`" softened to "may" (0 of 4 runs did).
- sampling-variance: with this reasoning model, temperature 0 did not make answers stable; the text now says some models and providers don't show the effect.
- Minor runtime text fixes found in the runs (plural agreement, duplicated cited keys, doubled punctuation, a conditional answer) — see the commit history.

Model behaviour is non-deterministic: one sample per exercise and language shows that the lessons run and that their claims are not contradicted by this model; it is not a statistical result.
