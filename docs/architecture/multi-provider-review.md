# 模型接入与执行证据

平台保留原生 HTTP 教学路径，并使用 LiteLLM SDK 适配其他供应商。课程仍负责自己的消息、工具与循环，模型连接统一由后端管理。

## 实现位置

- `server/providers.py`：服务商绑定、连接配置校验和后端临时内存配置。
- `course/providers.py`：模型连接类型与 LiteLLM 调用适配。
- `course/api_client.py`：百炼原生 HTTP 传输。
- `course/execution.py`：课程共享调用预算、取消与事件快照。

百炼原生入口读取 `local_config.py` 与 `DASHSCOPE_API_KEY`；其他服务使用各自的环境变量或网页提交的后端临时配置。变量列表和操作步骤见 [README](../../README.md#模型连接)。密钥不回显、不写入浏览器存储；切换供应商不会自动借用另一家的凭据。

## 证据表示

| 调用路径 | 观察器中的表示 | 边界 |
| --- | --- | --- |
| 百炼原生 HTTP | 完整请求与响应正文 | 认证头不进入事件 |
| LiteLLM SDK | 标准化请求与响应 | 经过 SDK 适配，不能冒充原始线上 HTTP 报文 |

一个 SDK 请求事件表示一次 SDK 调用，不保证等于一次底层网络尝试。未知 token usage 不计为零；模型工具提议与 Python 的实际执行分别记录。自定义课程使用共享 RunContext，不另建密钥读取与传输机制。

## 连接与运行边界

API Base URL 允许 HTTPS，或本机 localhost HTTP；拒绝包含认证信息、查询参数、片段及无效路径的地址。模型 ID 由用户按实际供应商填写，不能根据显示名称推断能力。Ollama 需要已有本地服务，平台不自动下载模型。

停止请求阻止后续调用；已发送的上游请求可能继续至响应或传输超时。配置只存在后端内存，重启后恢复环境变量和本地文件。平台面向单人本地学习，默认绑定 127.0.0.1。

供应商测试使用确定性响应。真实连接验证需另行配置并手动执行，会产生用量；测试通过不表示已验证所有厂商或模型。
