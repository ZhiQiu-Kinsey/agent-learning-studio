# 第 4 课：任务目标与验收

## 运行

在网页打开本课，选择预设，必要时修改结构化输入，点击运行。右侧证据板查看报告并展开事件；回放只读已有记录。本课完全本地运行，不需要模型密钥。正常、缺证据、错误结果三个预设使用同一任务卡和验收器；后两者是教学故障注入。修改 scenario 和 claim 可观察声称与验收分离。问题栏是学习者备注，会记在报告中；实际任务仍由结构化预设决定。

## 读源码与实验

runtime.py 中 TASK_CARD 定义范围、证据和停止条件；add_numbers 真正在 Python 执行；lesson.report 依据 tool_result 判断。无文件访问或外部副作用。按“预测结果→运行→对照请求/工具结果与报告→修改输入再试”的顺序练习。

## 限制与参考

本课没有读取外部任意路径，也没有长期状态。第 4 课仅证明固定本地案例的验收逻辑；第 5、6 课的实际模型表现依赖当前服务商，报告只依据本次响应。来源范围与固定 commit 见 [第二章来源记录](../../docs/architecture/chapter2-sources.md)。
