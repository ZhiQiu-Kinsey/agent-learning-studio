# 根据工具结果继续调用（`dependent-calls`）

**目标：**练习工具之间存在依赖时，模型如何先拿到事实，再决定下一步。

运行：

```powershell
# 在项目根目录运行
.\.venv\Scripts\python.exe main.py --lesson 2
```

试着输入：

> 把现在的小时和分钟相加。先读本机时间，再用实际返回的小时和分钟计算。

预期流程：

1. 第一次模型请求只调用 `get_current_time()`。
2. Python 返回带 `hour`、`minute` 的结构化数据。
3. 模型读取真实返回值，再请求 `add_numbers(hour, minute)`。
4. Python 将结果回传，模型组织最终回答。

这条路径最多用三轮模型请求。`main.py` 只保存本课的任务规则；两种工具和安全分发沿用“工具选择”一课，共用 API 客户端和执行循环。每轮的完整请求 JSON 会显示在终端中，认证头不会打印。实际百炼调用会产生用量。

本课也可在网页课程导航中进入，查看源码、真实运行事件和回放。
