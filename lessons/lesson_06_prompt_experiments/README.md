# 第 6 课：提示词与工具描述

## 运行

在网页打开本课，选择预设，必要时修改结构化输入，点击运行。右侧证据板查看报告并展开事件；回放只读已有记录。需要真实模型连接和两次模型调用预算。三个预设固定 user、模型和 temperature=0；工具预设只改 function.description，其他预设只改 system 规则。问题栏是学习者备注，会记在报告中，不改变固定的配对任务。

## 读源码与实验

runtime.py 的 TASKS 固定配对条件；工具预设检查真实 tool_calls 提议，另两个预设只做关键词形式初筛。报告表头“变更变量的文本”依预设显示工具 description 或 system 规则。初筛命中仍需人工核读两个原始 response，不能当作语义正确；工具提议不会被执行。单次配对不足以证明普遍效果，需扩充样本与重复运行。

## 限制与参考

本课没有读取外部任意路径，也没有长期状态。第 4 课仅证明固定本地案例的验收逻辑；第 5、6 课的实际模型表现依赖当前服务商，报告只依据本次响应。来源范围与固定 commit 见 [第二章来源记录](../../docs/architecture/chapter2-sources.md)。
