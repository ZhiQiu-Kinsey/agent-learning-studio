# 委派、上下文合并与预算（`delegation-budget`）

[English](README.md) · 简体中文

这一课回答一个问题：协调者已经决定把活拆给几个子 Agent，怎样交出去、怎样收回来，才能让每一步都查得清？任务固定为“回答关于期末项目的四个问题”（截止时间、每组人数、占总评比例、迟交规则），资料是五份虚构的短文（课程大纲、教务通知、小组规则、评分细则、迟交规定）。其中课程大纲和教务通知对截止时间说法不同，用来演示冲突。课程用 slug 指代其他课，不用会随课程表变化的课号。本课需要真实模型连接。

## 机制

协调者就是运行器（程序），不由模型担任：

- **委派契约。** 每个子任务一份契约：一个问题、分给它的资料编号、输出 JSON 的格式（`status`、`value` 不超过 40 字、`evidence`）、停止条件（只调用一次、找不到写 `not_found`、不许猜）、期限和优先级。子任务的上下文是全新的消息列表，只有契约和它自己的资料。
- **合并校验。** 运行器把所有按期交回的结果交给注册工具 `merge_check`：格式合法、`value` 不超长、必须带证据、每条原文逐字出现在它标的资料里、而且那份资料必须分给了这个子任务。通过的值按问题归并；同一问题的不同值作为冲突原样列出，不替谁裁决。
- **共享预算。** 模型调用数、服务商报告的 Token、全程时间放进一个账本（`SharedBudget`），子任务按优先级申请。调用数在发请求前扣，Token 只扣服务商报告的 `total_tokens`（没报告就记一次未报告，不估算，也不当成 0）。预算拒绝时写明原因，没开始的子任务全部列出。
- **取消传播。** 协调者持有根范围，每个子任务一个子范围；根范围取消一次，所有子范围都看得到。超过期限的子任务被取消、记为超时；它的请求已发出、收不回，所以收尾时等响应回来，用量记进账本，结果不参与合并（`lesson.late_response`）。
- **最终结论。** 由程序按固定顺序判：必需问题缺答案是“未完成”，有冲突是“待确认”，有子任务没做是“必需问题已答，有子任务没做”，全部通过且无冲突才是“全部完成”。最终回答也由程序从合并结果拼出，没有模型参与。

## 练习

| 练习 | 和基线差在哪 | 看什么 |
| --- | --- | --- |
| 契约齐全（基线） | 无 | 五个子任务各自的 `lesson.delegate` 上下文、`lesson.merge` 里的截止时间冲突、结论“待确认” |
| 契约缺证据要求 | 契约里删掉证据要求 | 交回的 JSON 没有 `evidence`，合并校验一个都不收（`no_evidence`），结论“未完成” |
| 共享预算很紧 | 调用预算 3 次 | `lesson.budget_stop`：`deadline-notice` 和 `late-policy` 没开始；没有交叉核对，所以没发现冲突 |
| 一个子任务超时 | `weight` 的期限 50 毫秒 | `lesson.subtask` 的 `timed_out_after_ms`、`lesson.late_response` 的 `discarded`、必需问题缺失，结论“未完成”但其余结果照常交付 |

证据主要在 `lesson.task_card`、`lesson.plan`、`lesson.delegate`、`lesson.subtask`、`lesson.budget_stop`、`lesson.late_response`、`lesson.merge` 和实验报告（`lesson.report`）里；并行请求各带自己的 `branch`（子任务编号），时间线据此配对请求和响应。

## 文件

| 文件 | 内容 |
| --- | --- |
| `runtime.py` | 自定义运行器：派工、等待、超时、收尾、合并、结论、事件和报告 |
| `contracts.py` | 契约、子任务上下文的生成、回复解析、合并校验 |
| `budget.py` | 共享预算和取消范围 |
| `locales/` | 中英文运行时文本：资料、问题、提示词、任务卡、报告 |
| `fixtures.py` | 只服务自动化测试的确定性回答；网页没有入口 |
| `content.json`、`content.en.json`、`lesson.json`、`lesson.en.json` | 教学内容和实现清单，及英文译文层 |
| `test_lesson.py` | 行为测试：真实执行合并校验、预算、取消、输入校验，两种运行语言 |

**运行语言：**本课支持中文和英文运行。资料、问题、子任务提示词、任务卡、问题代码说明、结论和报告文字写在 `locales/zh_CN.py` 与 `locales/en.py`；子任务编号、字段名、状态码和事件名是代码，各语言相同。网页按界面语言选择，运行记录里写明这次运行的语言。

## 运行

离线测试（夹具给出确定性回答，合并校验、预算和取消都是真实执行的）：

```powershell
.\.venv\Scripts\python.exe -m unittest lessons.lesson_delegation_budget.test_lesson -v
```

真实运行需要先配置模型（环境变量或 `local_config.py`），再启动服务：

```powershell
.\.venv\Scripts\python.exe run_web.py
.\.venv\Scripts\python.exe scripts/run_live.py delegation-budget full-contract --url http://127.0.0.1:8765 [--locale en]
```

真实运行会产生模型用量。本课目前仍是规划草稿：只做过离线验证，没有用真实模型运行过。

## 能证明与不能证明

- 逐字核对只能证明原文确实出自分给它的资料，不能证明 `value` 读对了。
- 本课的结论规则、优先级和子任务拆法都是为这个任务写死的，换个任务要重新定。
- 取消只能停止等待和后续动作，已发出的请求收不回，服务商照样生成和计量。
- 离线夹具里的回答、延迟和用量数字都是脚本写的；真实模型的表现以你自己的实验报告为准。
