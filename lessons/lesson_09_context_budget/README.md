# 第 9 课：上下文预算与压缩

默认运行会先执行一次本地资料读取，再向当前配置的模型发出 3 次请求，分别使用完整历史、窗口和规则压缩。`char_budget` 是 JSON 字符数上限，只约束压缩布局；它不是 token 容量。模型响应若含 `usage` 则原样列出，否则写未知。所有真实请求和响应由平台记录。

三组历史均由课程程序组装为受控上下文。其中 assistant 工具调用消息和旁支回复不是先前模型真实生成的；工具回执来自本次实际 Python 读取。压缩使用这条真实回执的来源与事实，是规则摘要，不调用另一个模型。自动测试的 `fixtures.py` 不用于学生的实时运行。参考与取舍见 `docs/architecture/budget-memory-sources.md`。
