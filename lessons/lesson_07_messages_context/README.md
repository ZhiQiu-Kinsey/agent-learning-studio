# 第 7 课：消息与上下文

本课使用当前配置的真实模型，默认每次运行发出 3 次请求：事实确认、完整历史追问、移除事实追问。“仅查看完整历史”预设发出 2 次。运行前请注意模型用量。相同追问的两条请求均遵守消息协议；模型结果不预设为正确。

`runtime.py` 实现请求构造、协议检查和从真实事件生成报告；`fixtures.py` 仅供离线测试。课程不提供学生环境的模拟回退。默认事实是练习样例，不是模型训练数据或工具执行记录。

参考范围见 `docs/architecture/context-state-sources.md`。浏览器动画解释机制，实际证据请看 request、response、lesson.report。
